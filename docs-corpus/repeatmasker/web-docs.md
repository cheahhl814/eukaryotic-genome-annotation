# RepeatMasker — repeatmasker.org (fetched 2026-10-21)

RepeatMasker screens DNA sequences for interspersed repeats and low-complexity DNA. Output: annotation of repeats plus a modified query (default: repeats replaced by Ns; use `-xsmall` for soft-masking — lowercase repeats). Search engines: nhmmer, cross_match, ABBlast/WUBlast, RMBlast, Decypher. Libraries: Dfam (profile HMM) and Repbase (GIRI). Over 56% of human genomic sequence is identified as masked.

Current versions (2026-06): RepeatMasker 4.2.4, RepeatModeler 2.0.9 — compatible with the Dfam 4.0 FamDB format. FamDB component-based framework allows downloading only the TE database portions needed.

Support: issues at https://github.com/Dfam-consortium/RepeatMasker/issues
Related: RepeatModeler (github.com/Dfam-consortium/RepeatModeler), RMBlast, RepeatScout, DupMasker — docs at repeatmasker.org.
